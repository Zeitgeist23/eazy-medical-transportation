Provider Data Sources

The core provider directory is built from the CMS National Plan and Provider Enumeration System (NPPES) monthly data dissemination. Eazy focuses on active records carrying taxonomy code 343900000X — Non-emergency Medical Transport (VAN).

What NPPES data can establish

NPPES can identify an NPI record, organization name, practice-location information, telephone number when present, taxonomy and update dates.

What NPPES data does not establish

NPPES does not by itself prove current ride availability, wheelchair capability, dialysis service, insurance-network participation, pricing, licensing status beyond the NPI record, or service quality. Those details should be verified directly.
